# ReFind – Website quản lý và tra cứu đồ thất lạc

## Giới thiệu

ReFind là website hỗ trợ quản lý và tra cứu thông tin đồ thất lạc trong trường đại học. Website giúp kết nối những người bị mất đồ với những người nhặt được đồ, góp phần nâng cao ý và tăng khả năng tìm lại đồ bị thất lạc.

Dự án được thực hiện nhằm xây dựng một giao diện website thân thiện, dễ sử dụng, hỗ trợ sinh viên đăng tin và tìm kiếm thông tin đồ thất lạc một cách thuận tiện.

## Mục tiêu dự án

- Hỗ trợ đăng tin báo mất đồ và đăng tin về đồ nhặt được.
- Xây dựng chức năng tìm kiếm, tra cứu đồ thất lạc theo tên, loại đồ, vị trí và thời gian.
- Hỗ trợ cập nhật trạng thái và chỉnh sửa thông tin tin đăng.
- Tạo môi trường kết nối giữa người mất đồ và người nhặt được đồ.
- Thiết kế giao diện tương thích với máy tính và điện thoại.


## Công nghệ sử dụng

| Công nghệ | Sử dụng |
|---|---|
| HTML5 | Xây dựng cấu trúc trang web |
| CSS3 | Thiết kế giao diện, bố cục và khả năng responsive |
| JavaScript | Xử lý tương tác, tìm kiếm, lọc tin và biểu mẫu |
| Git và GitHub | Quản lý mã nguồn và lưu trữ dự án |
| GitHub Pages | Triển khai website |
